Cómo añadir páginas

  1. Crea un archivo _build/empresa.mjs (o admin.mjs) con import { page, ... } from './lib.mjs'.
  2. Llama a page({ file: 'empresa/vacantes.html', title, face: 'empresa', header, body }). La barra superior con “Volver al inicio del prototipo” y el pie se añaden solos.
  3. Importa tu archivo en _build/build.mjs (junto a los de estudiante) y
  4. Ejecuta node prototipo/_build/build.mjs: regenera todos los .html y el CSS. Las rutas son relativas (../assets).
  5. Usa solo clases de esta guía y variables var(--...). Si falta algo, añádelo en _build/css/40-extra.css.
  6. “Cerrar sesión” debe llevar a ../estudiante/index.html (portada pública).
